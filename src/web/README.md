# Caldova web app

This Next.js app is one workspace of the
[Caldova banking project](../../README.md). Run installation, tests and
deployment commands from the repository root. `app/` contains the UI and API
routes, `components/` the banking experience, and `lib/agent.ts` the
primary system prompt, Foundry tool catalog and tool-call boundary.

`app/globals.css` imports the live root `styles.css`. Local preview
without Azure credentials is limited; see the root README for prerequisites
and the synthetic-data/approval boundaries.
